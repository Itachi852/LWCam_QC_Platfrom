# 任务和已完成界面重新设计计划

## 目标
重新设计质检相关界面的前端样式，不修改后端代码和业务逻辑，仅优化视觉效果和用户体验。

## 涉及文件
1. `frontend/src/views/qc/QcIndexView.vue` - 质检工作台（待处理、我的任务、已完成）
2. `frontend/src/views/admin/QcTaskManageView.vue` - 管理员任务管理

## 设计改进方向

### QcIndexView.vue 改进
1. **顶部统计卡片**
   - 添加渐变背景和图标
   - 改进数字展示效果
   - 添加微妙的阴影和悬停效果

2. **待处理队列**
   - 优化表格样式（去掉过多边框，增加行间距）
   - 改进操作按钮的视觉层级
   - 添加悬停效果

3. **我的任务工作台**
   - 左侧导航树：改进图标、间距和选中状态
   - 中间预览区：添加图片缩放效果、改进加载状态
   - 右侧元数据面板：优化字段展示、添加卡片式分组

4. **已完成历史**
   - 任务卡片添加阴影和悬停动画
   - 改进状态标签的颜色系统
   - 优化图片缩略图展示

### QcTaskManageView.vue 改进
1. **统计区域**
   - 添加卡片式设计
   - 改进数字强调效果
   - 添加图标和渐变背景

2. **表格优化**
   - 减少边框线条
   - 改进行悬停效果
   - 优化时长标签的视觉设计

3. **操作按钮**
   - 统一按钮样式
   - 改进危险操作的视觉提示

## 实现步骤
1. ✅ 读取现有代码
2. 重新设计 QcIndexView.vue 的样式部分
3. 重新设计 QcTaskManageView.vue 的样式部分
4. 测试响应式布局是否正常

## 设计原则
- 保持现有布局结构，只修改样式
- 使用现代化的设计语言（柔和阴影、圆角、渐变）
- 提升视觉层级和信息密度
- 保持 Element Plus 组件的兼容性
- 确保响应式设计不受影响
